STAYEASY - LOCAL STORAGE HOTEL BOOKING DEMO
===========================================

WHAT IS INCLUDED
- index.html: customer hotel listing, search, booking form and My Bookings.
- style.css: customer website styling.
- script.js: hotel demo data and Local Storage booking logic.
- admin.html: admin dashboard.
- admin.css: admin dashboard styling.
- admin.js: booking management, status update and CSV export.

12 DEMO CITIES
Gurugram, Faridabad, Delhi, Noida, Jaipur, Udaipur, Agra, Chandigarh,
Shimla, Haridwar, Bengaluru and Mumbai.

HOW TO RUN
1. Extract the ZIP file.
2. Open the StayEasy_Local_Demo folder.
3. Double-click index.html, or open it with Live Server in VS Code.
4. Choose a hotel and room, fill the form, and save a demo booking.
5. Scroll down to My Bookings to see it.
6. Open admin.html in the SAME browser to see the same booking.
7. In the admin dashboard, you can Confirm, Cancel, Delete cancelled
   demo bookings, Refresh, and Export CSV.

GITHUB PAGES
Upload all files (keep them in the same folder structure) to the root of
your GitHub repository. Open the published website URL in your browser.
Use the same exact website URL and same browser for both customer and admin
pages:
- https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
- https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/admin.html

IMPORTANT LOCAL STORAGE LIMITATIONS
- No Firebase, login, OTP, backend, or online database is used.
- Bookings are saved only in the current browser's Local Storage for this
  website origin.
- Customer page and admin page share bookings only when opened in the same
  browser profile and on the same website origin.
- They do not sync to another phone, computer, browser, or browser profile.
- Clearing browser site data can delete saved demo bookings.
- Anyone with access to this browser profile may be able to inspect local
  browser data. Do not enter real customer personal information.
- Hotel listings, room rates and booking statuses are sample data only.
  No real hotel reservation is created.
